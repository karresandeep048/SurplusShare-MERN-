01 / Problem Statement

The Food Waste Paradox & Market Gaps

🚨 Massive Edible Waste

Surplus from Commercial Food Providers

Restaurants, catering services, university canteens, and bakeries discard perfectly edible surplus food every single day due to lack of an immediate redistribution channel.

⏱️ Zero Perishable Support

Absence of Real-Time Coordination

Traditional food donation programs rely on slow batch logistics with long lead times, making same-day rescue of perishable hot meals and bakery items nearly impossible.

🔒 Verification & Alert Deficit

Uncoordinated & Unverified Pickups

Donors face operational chaos, unauthorized pickups, lack of instant arrival alerts, and no proof of handover. Receivers lack visibility into dietary compatibility.

Key Goal: Reduce commercial food waste while safeguarding recipient trust and food hygiene.
02 / Proposed Solution

SurplusShare: The Direct Hyperlocal Food Bridge

01

Donor Onboarding & Instant Postings

Suppliers post food batches in seconds with portion counters, dietary labels, expiry countdowns, and geo-coordinates.

02

Map-Based Community Discovery

Receivers search nearby food on an interactive Leaflet map, filter by distance (5-50km) and dietary tags (Veg, Vegan, Gluten-Free).

03

Atomic Inventory & Partial Claims

Real-time database decrement prevents overselling. Multiple community members can claim portions from a single bulk listing.

04

Interactive Email Pass Dispatch

Instant digital pickup passes sent to receivers and arrival alerts sent to donors with unique 6-digit OTP codes and resend options.

🌿 Impact Accounting: Dynamic carbon and water conservation algorithms quantify personal and community ESG milestones.

04 / System Architecture

MERN Stack Technical Architecture

Client Tier (React 18 + Vite)
  • • Styling: Tailwind CSS v4 + Lucide Icons
  • • Mapping: React-Leaflet + Custom Pins
  • • State & Auth: React Context + Axios Interceptors
  • • Email Sending UI: Direct 'Email Pass' buttons & test widgets
  • • Navigation: React Router v7
Application Tier (Express 5 + Node)
  • • REST API: Structured MVC separation
  • • Auth: JWT Bearer tokens + Bcrypt
  • • Email Pipeline: Nodemailer Gmail SMTP with timeouts
  • • Lifecycle: autoExpireItems() engine
  • • Verification: 6-digit OTP verification
Data Tier (MongoDB Atlas)
  • • ODM: Mongoose Schemas & Population
  • • Models: User, FoodListing, Reservation
  • • Indexing: Fast geospatial & status lookups
  • • Integrity: Atomic decrement & rollback
  • • Seeds: Idempotent multi-venue data
Modern microservice-ready modular architecture ensuring low latency and clean separation of concerns.
05 / Email Notification System

Upgraded Email & Automated Notification Pipeline

1. Instant Receiver Claim Pass

When a recipient claims food, an automated HTML email pass is dispatched containing the meal details, portion count, venue address, pickup window, and the unique 6-digit OTP code.

2. Real-Time Donor Claim Alert

Suppliers immediately receive an email notification alerting them of the reservation with recipient details, portion count, and safety instructions for preparing the food parcel.

3. On-Demand 'Email Pass' Option in UI

Users can click 'Email Pass' on MyReservations, Order Tracker, and Dashboard to send/resend their vouchers to any email address anytime.

4. Resilient Fallback & Diagnostics

Configured with Nodemailer Gmail SMTP (16-char App Passwords), 5-second socket timeouts, and self-healing formatted console logging so API requests never hang.

Fully decoupled asynchronous email dispatch guarantees zero lag on user interactions.
06 / Core Features

Key Innovation Highlights & Capabilities

📍 Geospatial Map Discovery

Live Leaflet map with pulsing urgent pins (⚡) and fresh pins (🌱). Dynamic radius filtering (5-50km) and distance calculation.

🔐 6-Digit Verification Terminal

Supplier terminal matches pickup OTP to confirm handover, prevent unauthorized collection, and increment rescued meal records.

🛵 Live Trip & Arrival Tracker

Visual route tracker with one-click 'Notify Arrival' triggering immediate email alerts to the supplier counter.

📧 Integrated Email Center & Passes

Direct 'Email Pass' and 'Resend Pass' buttons in the UI dispatching full HTML vouchers to user inboxes.

⏳ Autonomous Auto-Expiry

Self-healing lifecycle helper automatically archives past-due listings and rolls uncollected food portions back to safety.

📊 ESG Sustainability Metrics

Calculates CO2 emissions prevented, water saved, and money saved on personal profiles and community dashboards.

All features built natively into the SurplusShare codebase with zero external third-party paid dependencies.
07 / Data Design

Database Schema & Entity Models

User Model
name: String (Required)
email: String (Unique)
password: String (Hashed)
role: 'supplier' | 'receiver' | 'admin'
dietaryPreferences: [String]
location: String
profileImage: String
mealsRescued: Number (Default 0)
timestamps: true
FoodListing Model
supplier: ObjectId (Ref: User)
foodName, description: String
quantity, availableQuantity: Number
unit: "meals" | "kg" | "boxes"
foodType: Veg | Non-Veg | Vegan
pickupStart, pickupEnd: Date
expiryTime: Date
coordinates: { lat, lng }
status: AVAILABLE | RESERVED | ...
Reservation Model
foodListing: ObjectId (Ref: Food)
receiver: ObjectId (Ref: User)
quantity: Number
pickupCode: String (6-digit OTP)
status: RESERVED | COLLECTED | ...
pickerArrived: Boolean
arrivedAt: Date
reservedAt: Date
collectedAt: Date
Optimized relationships using Mongoose object population and atomic transactional queries.
08 / User Journey

End-to-End Operational Lifecycle

1

Listing Created

Supplier inputs food portions, expiry timer & venue location.

2

Map Discovery

Receiver discovers nearby listings filtered by radius and diet.

3

Claim & Email Pass

Portions reserved; 6-digit OTP generated & emailed with on-demand resend option.

4

Arrival Ping

Receiver arrives at counter; clicks 'Notify Arrival' on tracker.

5

OTP Handover

Supplier matches OTP code; status becomes COLLECTED & logged.

Seamless flow designed for ultra-fast transactions during peak restaurant and closing hours.
